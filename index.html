Nimbus

Your desktop
has a control tower.

Nimbus is a voice-activated overlay assistant for Windows. It waits in the system tray until you press Ctrl + Shift + Space — then it listens, works out what you actually meant, fetches the answer, and speaks it back on a card over whatever you were already doing.

Floor 01 — Radio room

Press to talk. Or just type.

A global hotkey lifts the overlay out of the tray from inside any application. The microphone opens, listens for the moment you stop, and closes itself — there is no stop button to hunt for.

  • Ctrl+Shift+Space raises the overlay from anywhere. Esc puts it away.
  • Speech is transcribed by Whisper — Groq's API by default, or the local model on floor 07.
  • Start typing and the mic closes on the first keystroke. Lead with / for the command palette.
  • Replies are spoken through the Web Speech API and drawn as a card you can read.
MediaRecorder Silence detection globalShortcut SpeechSynthesis

Floor 02 — Ops deck

Departures, delays,
and when to leave.

Live timetables come from Transitous/MOTIS and routing from Valhalla over OpenStreetMap. Ask for the next train and you get the board. Ask when to leave and it does the arithmetic against the live schedule.

  • Real-time departures with delay minutes, for any station you name or your configured default origin.
  • Multi-modal directions — car, bike, walk or transit — geocoded through Nominatim.
  • "Tell me when to leave" works backwards from the live timetable to a departure time.
  • Watch a journey and Nimbus notifies you when your train starts slipping.
Transitous / MOTIS Valhalla Nominatim OpenStreetMap

Floor 03 — Weather deck

Conditions aloft.

Open-Meteo needs no API key, so weather answers work the minute you install. And since this is a control tower, it will also tell you what is flying overhead.

  • Current conditions and forecast for your configured city, or anywhere you name.
  • Live aircraft overhead pulled from the OpenSky Network.
  • Weather is one of the sources folded into the daily briefing, alongside departures, reminders and news.
Open-Meteo OpenSky Network No key required

Floor 04 — Wire room

Everything coming
off the wire.

Headlines, tickers, trending repositories and deep research, all filed on one floor.

  • News headlines with thumbnails via Tavily, with GNews supplying per-article images.
  • Stock prices with 30-day sparklines from Yahoo Finance. No key needed.
  • Crypto with 7-day trends from CoinGecko.
  • GitHub trending, TV schedules, and a deep research mode that plans and runs several queries before answering.
Tavily GNews Yahoo Finance CoinGecko GitHub REST TVMaze

Floor 05 — The archive

It remembers,
and it reads.

A rolling conversation history, a shelf of long-term facts you dictate, and an archive of past answers you can search by voice. Point it at the screen and it reads whatever is there.

  • 12-turn rolling context, plus up to 40 long-term facts — "remember that I take the RB68 to work".
  • Ctrl+Shift+S captures a region of the screen for vision analysis. It is held for the turn, then cleared.
  • Ctrl+Shift+A acts on selected text: fix, rewrite, summarise, explain, translate.
  • Paperwork mode pulls the deadline, the amount and the action required out of official letters, and explains them in your native language.
  • Reminders and events that expire on their own once the last day passes.
Ctrl+Shift+S Ctrl+Shift+A Vision Paperwork mode

Floor 06 — Switchboard

Every voice on the line,
labelled.

Nimbus captures the meeting, separates the speakers and writes it down as it happens. The same machinery gives you subtitles for anything playing on screen.

  • Live meeting transcription with speaker diarization.
  • Live subtitles generated for films and video as they play.
  • Audio ducking — whatever is playing drops in volume while Nimbus is speaking.
  • Internet radio through Radio-Browser, and YouTube search that hands off to the browser.
Diarization Live subtitles Radio-Browser Ducking

Floor 07 — Signal room

Cut the uplink.

Three models run on your own GPU through WebGPU. Swap them in and Nimbus stops calling out at all — no key, no request, nothing leaving the machine.

  • Qwen 3.5 0.8B (532 MB) replaces Gemini for local inference.
  • Whisper base (290 MB) replaces the Groq key for speech recognition.
  • Kokoro 82M (330 MB) for local text-to-speech, around 600 ms a sentence.
  • WebGPU earns its keep: Whisper runs in 690 ms against 4,742 ms on CPU.
  • When you do use cloud keys, they never reach the renderer — services run in the main process and keys are encrypted at rest with Windows DPAPI via Electron safeStorage.
WebGPU ONNX Runtime No ambient capture safeStorage

Getting it running

Hotkeys

CtrlShiftSpace
Show or hide the overlay. Configurable.
CtrlShiftS
Capture the screen for analysis.
CtrlShiftA
Act on the currently selected text.
Esc
Close the overlay.

What you need

  • Windows. The current implementation is Windows-only.
  • Node.js, to run the dev server.
  • A microphone for voice input.
  • A GPU is optional — WebGPU acceleration via ONNX Runtime if you have one.
  • Display capture for the meeting and subtitle features.

Free API keys

  • GEMINI_API_KEY — chat and intent classification.
  • GROQ_API_KEY — speech to text.
  • TAVILY_API_KEY — web search and news, 1,000 a month free.
  • GNEWS_API_KEY — article thumbnails. Optional.
  • GITHUB_TOKEN — raises rate limits. Optional.

Weather, transit, maps, stocks and crypto need no key at all. Swap in the local models and you need none of them.

Four commands

git clone https://github.com/ahmed-babay/nimbus
npm install
cp .env.example .env    # then fill in your keys
npm run dev

Then press Ctrl Shift Space, or right-click the tray icon and choose Show Nimbus. Integrations, location, language and wake word are all toggled in config.json.
