Nimbus

The assistant that lives
one keystroke away.

A voice-activated AI assistant for Windows. It waits in the system tray until you press Ctrl Shift Space — then it hears you, works out what you meant, fetches the answer, and speaks it back over whatever you were already doing.

01 — Voice

It hears you the moment you ask.

A global hotkey pulls the overlay out of the tray from inside any application. The microphone opens, listens for the moment you stop, and closes itself — there is no stop button to hunt for.

  • Ctrl+Shift+Space raises the overlay from anywhere. Esc dismisses it.
  • Speech is transcribed by Whisper — Groq's API by default, or the local model in section 07.
  • Auto-stop on silence. No press-and-hold, no timing it yourself.
  • Start typing and the mic closes on the first keystroke. Lead with / for the command palette.
  • Answers are spoken through the Web Speech API and drawn as a card you can read.
MediaRecorder Whisper globalShortcut SpeechSynthesis

02 — Intent

It works out what you
actually meant.

Every utterance is classified and its parameters extracted before anything is fetched. Structured JSON output turns "when's the next train to Frankfurt" into a typed call rather than a guess.

  • Intent classification and parameter extraction through Gemini's structured output.
  • Routed straight to the right service — direct REST calls, no server subprocess to spawn.
  • 12-turn rolling history, so follow-ups land without repeating yourself.
  • Answers come back as rich cards: charts, maps, departure boards, images.
  • A command palette on / for when you would rather point than talk.
Gemini Structured output Response cards

03 — Signals

Live data, no keys required.

Weather, transit and routing all run on open endpoints. They work the minute you install, before you have signed up for anything.

  • Weather from Open-Meteo. No API key, ever.
  • Real-time departures with delay minutes via Transitous/MOTIS.
  • Multi-modal directions — car, bike, walk, transit — through Valhalla, geocoded by Nominatim over OpenStreetMap.
  • "Tell me when to leave" works backwards from the live timetable.
  • Watch a journey and Nimbus notifies you when your train starts slipping.
  • Live aircraft overhead, from the OpenSky Network.
Open-Meteo Transitous / MOTIS Valhalla Nominatim OpenSky

04 — Wire

Everything coming
off the wire.

Headlines, tickers, trending repositories, and a research mode that plans and runs several queries before it answers you.

  • News with thumbnails via Tavily, with GNews supplying per-article images.
  • Stock prices with 30-day sparklines from Yahoo Finance. No key.
  • Crypto with 7-day trends from CoinGecko.
  • GitHub trending repositories and TV schedules.
  • Deep research mode plans a set of queries, runs them, then answers.
  • A daily briefing folds weather, departures, reminders and news into one reply.
Tavily GNews Yahoo Finance CoinGecko GitHub REST TVMaze

05 — Recall

It remembers,
and it reads your screen.

A rolling conversation history, a shelf of long-term facts you dictate, and an archive of past answers you can search by voice. Point it at the screen and it reads whatever is there.

  • Up to 40 long-term facts — "remember that I take the RB68 to work".
  • Ctrl+Shift+S captures a region of the screen for vision analysis. Held for the turn, then cleared.
  • Ctrl+Shift+A acts on selected text: fix, rewrite, summarise, explain, translate.
  • Paperwork mode pulls the deadline, the amount and the action required out of official letters, and explains them in your native language.
  • Reminders and events that expire on their own once the last day passes.
Ctrl+Shift+S Ctrl+Shift+A Vision Paperwork mode

06 — Room

Every voice in the room,
labelled.

Nimbus captures the meeting, separates the speakers and writes it down as it happens. The same machinery subtitles anything playing on screen.

  • Live meeting transcription with speaker diarization.
  • Live subtitles generated for films and video as they play.
  • Audio ducking — whatever is playing drops in volume while Nimbus speaks.
  • Internet radio through Radio-Browser, and YouTube search that hands off to the browser.
Diarization Live subtitles Radio-Browser Ducking

07 — Local

Cut the uplink.

Three models run on your own GPU through WebGPU. Swap them in and Nimbus stops calling out at all — no key, no request, nothing leaving the machine.

  • Qwen 3.5 0.8B (532 MB) replaces Gemini for local inference.
  • Whisper base (290 MB) replaces the Groq key for speech recognition.
  • Kokoro 82M (330 MB) for local text-to-speech, around 600 ms a sentence.
  • WebGPU earns its keep: Whisper runs in 690 ms against 4,742 ms on CPU.
  • Cloud keys never reach the renderer — services run in the main process, encrypted at rest with Windows DPAPI via Electron safeStorage.
  • Explicit capture only. No ambient screen buffering, no clipboard watching.

Ignition

Bring the core online.

Nimbus is open source and runs from source today. Packaging a signed .exe with electron-builder is deliberately out of scope for this version, so the way in is to clone it and start the dev server.

Hotkeys

Show or hide the overlay. Configurable.
CtrlShiftS
Capture the screen for analysis.
CtrlShiftA
Act on the currently selected text.
Esc
Close the overlay.

What you need

  • Windows. The current implementation is Windows-only.
  • Node.js, to run the dev server.
  • A microphone for voice input.
  • A GPU is optional — WebGPU acceleration through ONNX Runtime if you have one.
  • Display capture for the meeting and subtitle features.

Free API keys

  • GEMINI_API_KEY — chat and intent classification.
  • GROQ_API_KEY — speech to text.
  • TAVILY_API_KEY — web search and news, 1,000 a month free.
  • GNEWS_API_KEY — article thumbnails. Optional.
  • GITHUB_TOKEN — raises rate limits. Optional.

Weather, transit, maps, stocks and crypto need no key at all. Swap in the local models and you need none of them.

Four commands

git clone https://github.com/ahmed-babay/nimbus
npm install
cp .env.example .env    # then fill in your keys
npm run dev

Then press Ctrl Shift Space, or right-click the tray icon and choose Show Nimbus. Integrations, location, language and wake word are all toggled in config.json.
